# Ruby Language 💎

Repositório dedicado aos meus estudos, testes e experimentações com a linguagem de programação **Ruby**. Aqui compartilho códigos, conceitos e pequenos projetos desenvolvidos durante minha jornada de aprendizado.

---

## 🚀 Sobre o Projeto

O objetivo deste repositório é explorar a sintaxe elegante, a orientação a objetos pura e os recursos idiomáticos do Ruby, construindo uma base sólida na linguagem.

---

## 🛠️ Tecnologias

* **Linguagem:** Ruby
* **Gerenciador de Versões:** [RVM (Ruby Version Manager)](https://rvm.io/)
* **Controle de Versão:** Git & GitHub

---

## ⚙️ Como Executar

Certifique-se de ter o Ruby instalado em sua máquina (você pode utilizar o [RVM](https://rvm.io/) para gerenciar a instalação e as versões da linguagem). Para verificar a versão atual:

```bash
ruby -v
